# JARVIS Mobile Command Center V1

Phone-first, local-first Mission Control console for Jake.

## Current status

**SOURCE PUBLISHED / GITHUB PAGES ACTIVATION REQUIRED**

The application source is on the `main` branch. To activate the HTTPS site:

1. Open repository **Settings**.
2. Open **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

Expected address after activation:

`https://adudeandhistech.github.io/hello-jarvis2/`

## Phone installation

Open the live address in iPhone Safari, tap **Share**, select **Add to Home Screen**, and confirm **JARVIS MCC**.

## Data boundary

The public repository contains application code only. Records and attachments created in the application are stored locally in the device browser database unless the operator exports them. No email, cloud account, Mission Control vault, or autonomous agent is connected in V1.
